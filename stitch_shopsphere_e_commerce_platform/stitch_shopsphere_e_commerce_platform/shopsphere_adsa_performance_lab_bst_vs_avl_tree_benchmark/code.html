Algorithmic Deep Dive & Mathematical Invariants

Core proofs ensuring balanced indexing performance in ShopSphere product routing.

Binary Search Tree Ordering Property

For any given tree node u, every node key in the left subtree of u is strictly less than u.key, and every node key in the right subtree is strictly greater than u.key.

// Formal Invariant:

∀ v ∈ u.left ⇒ v.key < u.key

∀ w ∈ u.right ⇒ w.key > u.key

While search in an average BST takes logarithmic time, BSTs make no height guarantee. Inserting sorted product SKUs results in a degenerate list where every search degrades to Θ(N).

sort

In-Order Traversal Invariant

An in-order traversal of a valid BST always yields keys sorted in monotonically ascending order.

The Balance Factor (BF) Theorem

An AVL tree is a self-balancing binary search tree where the heights of the two child subtrees of any node differ by at most one:

BalanceFactor(u) = Height(u.left) - Height(u.right)

Strict Invariant: BalanceFactor(u) ∈ {-1, 0, +1}

If at any point during an insertion or deletion |BF(u)| ≥ 2, the tree is rebalanced by executing at most two constant-time tree rotations (O(1)).

balance

Adelson-Velsky & Landis

First dynamically self-balancing tree discovered (1962), guaranteeing worst-case search within 1.44 log₂(N).

Left-Left (LL) Single Right Rotation
rotate_right

Applied when insertion is in left subtree of left child (BF = +2, child BF = +1).

Right-Right (RR) Single Left Rotation
rotate_left

Applied when insertion is in right subtree of right child (BF = -2, child BF = -1).

Left-Right (LR) Double Rotation
sync_alt

Left rotate left child, then Right rotate parent node (BF = +2, child BF = -1).

Degenerate Skew & Production Risks

In real-world e-commerce catalogs, products are frequently added with sequentially increasing database auto-increment IDs (e.g. 1001, 1002, 1003...).

If an index uses a standard BST, sequential inserts degrade the tree into a right-leaning singly-linked list. Search lookups become O(N) scans, triggering CPU spikes and FastAPI request timeouts.

dangerous ShopSphere SLA requires <1.5ms catalog retrieval. Unbalanced trees breach this SLA at N ≥ 4,000 items.
