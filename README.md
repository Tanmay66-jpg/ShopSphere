# ShopSphere 🛍️

**Everything Worth Finding.**

ShopSphere is a modern e-commerce product search and management platform that demonstrates the practical application of Advanced Data Structures and Algorithms in real-world shopping systems.

Built with React, Tailwind CSS, Python FastAPI, and SQLite, ShopSphere combines an interactive shopping experience with efficient product indexing and retrieval mechanisms.

### ✨ Key Features

- **Product Discovery:** Browse a curated catalogue of 50 products across Electronics, Fashion, Home & Living, and Accessories.
- **Smart Product Search:** Search products using product IDs and names.
- **Price Filtering:** Find products within specific price ranges.
- **Product Management:** Add, update, delete, and manage product records.
- **BST Implementation:** Organise and retrieve products using Binary Search Trees.
- **AVL Tree Implementation:** Maintain balanced product indexes through automatic tree rotations.
- **Name-Based Indexing:** Search and organise products alphabetically.
- **ADSA Performance Lab:** Visualise tree operations and compare algorithm performance across different dataset sizes.

### 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **Data Structures:** Binary Search Tree, AVL Tree, Price Index
- **Development Tools:** VS Code, Antigravity

### 🎯 Project Objective

The primary objective of ShopSphere is to bridge the gap between theoretical data structures and practical software development by integrating advanced searching and indexing algorithms into a functional e-commerce application.

Rather than demonstrating algorithms independently, ShopSphere showcases how these structures can support efficient product discovery and management in a real-world application.
